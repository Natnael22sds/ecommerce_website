# 🛍️ Yana Shop – Online Clothing Store

**Yana Shop** is a modern, responsive web application offering a curated selection of luxury clothing items. Built with PHP and HTML, it provides an intuitive interface for users to browse and explore various fashion categories.

---

## 🎯 Features

- **Product Categories**: T-shirts, Trousers, Two-piece sets
- **Responsive Design**: Optimized for desktops and mobile devices
- **Contact Form**: Users can submit inquiries with their name, phone number, and email
- **Social Media Integration**: Links to Instagram, Facebook, and Telegram
- **About Us Section**: Information about the brand and its offerings
- **Branch Locations**: Details on physical store locations

---

🛠️ Tech Stack
PHP – Backend scripting

HTML/CSS – Frontend structure and styling

JavaScript – Interactive elements

Responsive Design – Ensures usability across devices
